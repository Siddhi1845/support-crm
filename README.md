# 🎫 Support CRM

A modern Customer Support Ticket Management System built with **React, Node.js, Express, and SQLite**.

Support CRM helps organizations efficiently manage customer issues, track ticket progress, and streamline support operations through a role-based dashboard for both customers and administrators.

---

## ✨ Features

### 👤 Customer Module

* User Registration & Login
* Create Support Tickets
* View Personal Tickets
* Track Ticket Status
* Manage Profile

### 👨‍💼 Admin Module

* Dashboard Overview
* View All Tickets
* Search Tickets
* Filter Tickets by Status
* Update Ticket Status
* Update Ticket Priority
* Add Internal Notes
* Delete Tickets

### 🔐 Authentication & Security

* Role-Based Access Control
* Session Management using Local Storage
* Protected Routes

---

## 📊 Ticket Workflow

```text
Customer Creates Ticket
          ↓
Admin Reviews Ticket
          ↓
Status Updated
(Open → In Progress → Closed)
          ↓
Customer Tracks Progress
```

## 🚀 Installation & Setup

### Clone Repository

```bash
git clone https://github.com/Siddhi1845/support-crm.git
cd support-crm
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

Backend runs on:

```text
http://localhost:5000
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```text
http://localhost:5173
```
